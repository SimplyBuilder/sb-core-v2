# SimplyBuilder Core

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**SimplyBuilder Core v2** monorepo — JavaScript ecosystem for declarative DOM interface creation with event and memory management.

## Packages

| Package | Description |
|---------|-------------|
| `@simplybuilder/core` | Unified layer integrating DOM and Event |
| `@simplybuilder/core-dom` | DOM element creation and manipulation |
| `@simplybuilder/core-event` | Event management with cleanup |

## Prerequisites

- **Node.js** >= 18
- **pnpm** >= 9

## Installation and Build

```bash
pnpm install
pnpm build
```
